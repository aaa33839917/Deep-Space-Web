帮助文档

从下载到进游戏，按你的系统看对应的一段。遇到问题先翻「常见问题」。

快速开始

三步，不需要公网 IP，也不需要改路由器。

  1. 下载并安装：选你当前的系统，装好打开。首次连接会弹一次系统授权，用来创建虚拟网卡。
  2. 点「连接」：客户端会自动完成组网和身份校验，不需要填任何配置。
  3. 进游戏：状态显示「已连接」后，启动 Minecraft 进入服务器。

安装包已自带组网核心，不需要另外安装 EasyTier。

下载安装包

安装包都在下载页：安卓是 APK，Windows 是 exe，Linux 是 AppImage / deb。

不确定该下哪个：桌面电脑选 Windows 或 Linux，手机选安卓通用包即可。

安卓版

  1. 下载并打开 APK；系统提示「不允许安装未知应用」时选择允许。
  2. 打开应用，点主界面的连接按钮；首次连接会弹「VPN 连接请求」，选择允许。
  3. 状态显示「已连接」后，打开 Minecraft 进服。

VPN 权限是用来创建虚拟网卡的。不允许的话会连不上，但不会改动你手机里的其它设置。

Windows 版

  1. 双击安装包，一路「下一步」；安装时会弹一次 UAC，选择「是」。
  2. 装完打开桌面图标，点「开启加速」；这时会再弹一次 UAC，选择「是」。
  3. 状态显示「已连接」后，启动 Minecraft 进服。

安装和首次连接各会弹一次 UAC，都是系统权限确认，不是错误。

Linux 版

  1. AppImage 先加执行权限；或者安装 deb（会自动装好 helper 与 polkit 策略）。
  2. 首次连接会弹系统授权框，允许后创建虚拟网卡。
  3. 状态变为「已连接」后，启动 Minecraft。
chmod +x DeepSpace-linux-*.AppImage

常见问题

一直连不上

先确认客户端处于「已连接」状态，再切换网络重试。校园网、公司网络可能会拦截组网流量。

Windows 提示「已保护你的电脑」

程序没有购买代码签名证书，这是 SmartScreen 的常规提示。确认安装包来源后，点「更多信息 → 仍要运行」。

连上了，但进不去服务器

等状态变成「已连接」再启动游戏；仍然进不去就断开重连一次。

检查更新失败

更新走组网通道，先连上再检查更新。反复失败可以带截图到群里反馈。

隐私与安全

联机工具只做它该做的事：建网、校验身份、把游戏流量送到该去的地方。

不收集行为：页面与客户端不接第三方统计，不记录你去了哪里。

只做必要的绑定：账号与设备只用于登录与封禁，不上传键盘、文件或聊天内容。

本地校验：更新清单在本地验签，拒绝被篡改的安装包。
