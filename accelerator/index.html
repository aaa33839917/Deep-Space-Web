安卓版安装步骤

  1. 点击上方按钮，进入文件分享页后再次点击下载。
  2. 下载完成后打开安装包，系统会提示「不允许安装未知应用」，请选择允许。
  3. 安装完成后打开应用，点击主界面的连接按钮；首次连接时系统会弹出 「VPN 连接请求」，请选择允许。
已安装官方 EasyTier 的用户可直接覆盖安装，无需先行卸载，原有配置不会丢失。

Windows 版

版本v1.0.0
大小约 2.9 MB · 64 位单文件
文件名DeepSpace.exe
更新方式启动时自动检查更新
⬇️ 下载 Windows 版
使用前提：本程序不含 EasyTier 核心。 请把官方 EasyTier Windows 版与本程序解压到同一个文件夹，再双击运行。

Windows 版使用步骤

  1. 解压官方 EasyTier Windows 版，把 DeepSpace.exe 放进同一个文件夹。
  2. 双击 DeepSpace.exe，Windows 会弹出提权（UAC）请求，选择是。
  3. 窗口中显示 easytier-core 已启动 即为连接成功； 之后每次打开都会自动检查并安装新版本。
本程序没有代码签名，首次运行 Windows 可能提示「已保护你的电脑」。 确认来源可靠后，可点「更多信息」→「仍要运行」。

连接后可访问的服务

连接后在 Minecraft 中添加服务器：
地址 10.144.144.1　端口 25565（Java 版）／ 19132（基岩版）
（基岩版端口为 UDP；请保持客户端为最新版本）

常见问题

  1. 请确认已处于连接状态（安卓端通知栏应显示 VPN 图标）。
  2. 若长时间处于连接中，请尝试切换网络环境。
  3. 若仍无法连接，请附界面截图通过 QQ 群反馈。
