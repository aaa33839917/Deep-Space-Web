使用教程

从下载到进游戏，按你的系统选一段看即可。

先拿到安装包

安装包在下载页：安卓是 APK，Windows 是 exe，Linux 是 AppImage / deb。安装包已自带组网核心，不需要再装 EasyTier。

安卓版

  1. 下载并打开 APK；系统提示「不允许安装未知应用」时选择允许。
  2. 打开应用，点主界面的连接按钮；首次连接会弹「VPN 连接请求」，选择允许。
  3. 状态显示「可进游戏」后，打开 Minecraft 进服。

Windows 版

  1. 双击安装包，一路「下一步」；安装时会弹一次 UAC，选择「是」。
  2. 装完打开桌面图标，点「开启加速」；这时会再弹一次 UAC，选择「是」。
  3. 状态显示「连接成功，可以进游戏了」即可。

Linux 版

  1. AppImage 先 chmod +x；或安装 deb（会自动装好 helper 与 polkit 策略）。
  2. 首次连接会弹系统授权框，允许后创建虚拟网卡。
  3. 状态变为「可进游戏」后启动 Minecraft。

常见问题

  • 一直连不上：确认客户端处于已连接状态，再切换网络重试。
  • Windows 提示「已保护你的电脑」：程序未购买代码签名证书，确认来源后点「更多信息 → 仍要运行」。
  • 仍无法进入：带界面截图到 QQ 群 716121482 反馈。
