深空联机工具
用于深空旗下游戏服务器及其他服务的网络接入
介绍 使用教程 下载

先拿到安装包

安装包在下载页。安卓是 EasyTier-MC.apk， Windows 是 DeepSpace-Setup.exe（双击一路下一步就行，见下）。

⬇️ 去下载页

安卓版安装步骤

  1. 在下载页点击按钮，进入文件分享页后再次点击下载。
  2. 下载完成后打开安装包，系统会提示「不允许安装未知应用」，请选择允许。
  3. 安装完成后打开应用，点击主界面的连接按钮；首次连接时系统会弹出 「VPN 连接请求」，请选择允许。
已安装官方 EasyTier 的用户可直接覆盖安装，无需先行卸载，原有配置不会丢失。

Windows 版安装步骤

  1. 在下载页点击按钮，进入文件分享页后再次点击下载，得到 DeepSpace-Setup.exe。
  2. 双击它，一路「下一步」装完。安装这一步会弹一次提权（UAC）请求，选择是。
  3. 装完桌面上会出现「深空联机工具」图标，双击打开 —— 这次不弹 UAC，秒开。
  4. 点窗口里的大按钮「开启加速」，这时才弹一次 UAC（后台组网进程要管理员权限）， 选择是。
  5. 界面显示「连接成功，可以进游戏了」，就可以开游戏进服了。
安装包已经自带 EasyTier 核心、网卡驱动和界面文件 —— 不用再单独下载官方 EasyTier，也不用把几个文件凑到同一个文件夹。 以后有新版本，它会自动下载新的安装包并校验签名后升级。
本程序没有购买代码签名证书，首次运行 Windows 可能提示「已保护你的电脑」。 确认来源可靠后，可点「更多信息」→「仍要运行」。

常见问题

  1. 请确认已处于连接状态（安卓端通知栏应显示 VPN 图标）。
  2. 若长时间处于连接中，请尝试切换网络环境。
  3. 若仍无法连接，请附界面截图通过 QQ 群反馈。
